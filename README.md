# Longhand

Van Maanen Ventures LLC

Public, scrubbed operator template: durable brain scaffolding, eight shipping routines, three skills, and data stubs.

## Layout

- `brain/` — source-of-truth scaffolding (`index.md`, `rules.md`, empty ledgers)
- `routines/` — eight scrubbed job texts (folder slug = install id)
- `skills/` — `ping`, `scorecard`, `memory`
- `data/` — example-only stubs for watch-feed and unsubscribe lists

Replace angle-bracket placeholders (`<brain>`, `<your-channel>`, …) before you run anything live.
